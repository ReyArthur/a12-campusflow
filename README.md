# CampusFlow — Relatório Operacional e Análise de Dados (A12)

Este repositório contém a solução do caso operacional da **Central Acadêmica (CampusFlow)** desenvolvida em Python com PyMongo. O objetivo é transformar hipóteses gerenciais em evidências concretas a partir da análise da base de dados MongoDB.
